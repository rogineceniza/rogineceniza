# Setup — Rogine's cozy GitHub profile

1. Create/open the **public** GitHub repository `rogineceniza/rogineceniza`.
2. Copy `README.md`, `.github/workflows/` and `assets/` into the repository, retaining the directory structure.
3. Remove any old `pacman.yml`, `rain-snake.yml`, or other workflows that generate contributions you no longer want. Delete the old Pac-Man snippet from any prior README (the packaged README does not include it).
4. Open **Settings → Actions → General**. Under **Workflow permissions**, allow read and write permissions for GitHub Actions if necessary. This is needed for workflows that commit results.
5. Go to **Actions → Rainy Isometric Contribution City → Run workflow**. Once it successfully commits `assets/rainy-city.svg`, the image appears in your README. The 3D city is an isometric contribution calendar (not an actual three-dimensional city scene).
6. **Optional WakaTime coding-log setup:** install the WakaTime plugin in your code editor and configure it. In repository **Settings → Secrets and variables → Actions**, create repository secret `WAKATIME_API_KEY`. Under the **Variables** tab create `ENABLE_WAKATIME` with value `true`. Run **Coding Log (WakaTime)** and check that the generated stats appear between the `waka` markers in `README.md`.
7. You can replace the externally hosted cat GIF with any meme you have permission to use. `assets/rainy-desk.gif` is hosted in your own repository.

## About the uploaded bar chart

The supplied `bar_graph.png` shows 2023–2024 LOC values for C and HTML but is not known to represent the activity on `rogineceniza`. It is deliberately **not included as actual stats**. WakaTime can give you genuine coding-time/language metrics once connected. GitHub's repository-based language stats reflect repository content, not WakaTime hours.

## Customizing personal details

The project boxes are broad descriptions of work areas, not claims that particular public repositories already exist. You can replace the two generic GitHub repository links with actual project URLs when ready. The `side_quests` section is playful copy and can be edited to match your actual hobbies.
